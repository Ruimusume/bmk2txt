# bmk2txt
![Github latest downloads](https://img.shields.io/github/downloads/Ruimusume/bmk2txt/total.svg)

Convert the bmk file exported by [PointerSearcher-SE](https://github.com/tomvita/PointerSearcher-SE) into a txt text file.

A Python script for converting bmk files exported by [PointerSearcher-SE](https://github.com/tomvita/PointerSearcher-SE) into txt text files. This is intended for cases where the results exceed 10,000 entries and can no longer be rendered/displayed in the GUI.

### How to use
[Python 3.7.9](https://www.python.org/downloads/release/python-379/) is required to run this script.

Just put the .py file and the .bmk file in the same folder, then double-click to run it and it will output the txt text result.
